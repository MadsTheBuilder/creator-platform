# Brief: structure

**Goal:** how videos are built: openings beat by beat, body shapes, endings, and the transferable mechanisms.

Read `_contract.md` first.

**Inputs:** `captions/<id>.txt` (full transcript), `captions/<id>.cuts.txt`, `frames/hook-<id>.jpg`, `frames/dense-<id>-01.jpg`, and `captions/<id>.info.json` chapters.

**Produce:**
1. **Opening beat tables** for at least 3 videos (prefer the best-viewed, plus one from each era). Use the columns `Time | Spoken idea | Visual change | Sound cue | Viewer question | Payoff`, covering the first 60–90s. In Payoff, give the timestamp where the viewer question is answered later in the video, which you find in the transcript. Write "n/a" for sound you cannot infer; the audio data is coarse.
2. **The opening pattern in one line per video**, e.g. "strange detail → superlative → comparison → cliffhanger → promise".
3. **Body shapes:** one outline per video type (e.g. chronology, explainer, listicle, essay), with the section order and approximate timestamps.
4. **Endings:** how each video closes (summary, aphorism, question to comments, call to action) and whether that changed by era.
5. **Transferable mechanisms:** 6–12 reusable techniques, each with a citation and one sentence on why it works.
6. **Don't copy:** devices that would distract or that belong to the creator's identity.
