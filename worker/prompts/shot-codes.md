# Shot vocabulary

## Magnification (column C) — use only these codes
Combine with `/` when a shot is both a framing and a type, e.g. `OTS / MCU`, `POV / CU`, `2S / MS`.

| Code | Meaning | Typical use |
|---|---|---|
| EWS / ELS | Extreme wide / extreme long | Geography, scale, the city, isolation |
| WS / LS | Wide / long | Whole body in environment, blocking, entrances |
| FS | Full shot | Head to toe, costume, physical comedy |
| MLS | Medium long (knees up) | Walk-and-talks, groups standing |
| MS | Medium (waist up) | Default conversational coverage |
| MCU | Medium close-up (chest up) | Interviews, reactions, most emotion |
| CU | Close-up (face) | Key emotion, decisions |
| ECU | Extreme close-up (eyes, hands, object detail) | Clues, tension, beats that must not be missed |
| OTS | Over the shoulder | Dialogue, interrogation, confrontation |
| POV | Character's point of view | Put the audience in someone's head |
| 2S / 3S / GS | Two-shot / three-shot / group shot | Relationships, power balance, ensembles |
| INS | Insert | Object or detail cut into a scene (phone screen, document, product) |
| CI | Cutaway insert | Leaves the scene's action: B-roll, environment, symbolic image |
| GFX | Graphics only, no camera | Maps, text cards, lower-thirds, data. Lens = `N/A` |

User shorthand: c = close, m = medium, l = long, s = shot, e = extreme, cu = close-up.

## Lens (column E) — focal length in mm, full-frame equivalent
- 14–24: wide, distortion, scale, unease up close, drone
- 28–35: natural wide, handheld documentary, walk-and-talk
- 40–50: neutral, "honest" eye
- 85–100: portrait, compression, intimacy, isolation from background
- 135–200+: long lens, surveillance feel, crowds compressed, voyeurism
- `100 Macro`: object detail. `N/A` for GFX.
- AI-generated or 3D: still write a focal length; the generator prompt uses it.

## Angle (column F)
Eye level, High, Low, Top down / Bird's eye, Worm's eye, Dutch, Over the shoulder, POV, Profile, Child's eye level (low), Slightly low/high.

## Movement (column D)
Static, Locked-off, Pan, Tilt, Whip pan, Push in / Dolly in, Pull out, Track / Truck, Arc, Crane up/down, Jib, Drone (push/orbit/reveal/top-down), Gimbal follow/lead, Handheld (steady / nervous), Slider, Rack focus, Snap zoom, Crash zoom, Speed ramp, Slow motion (48/60/120 fps), Timelapse, Hyperlapse, Rig/car mount, Steadicam, VFX/virtual move.
Combine with `+` when one shot has two moves: `Drone push in + slow tilt down`.

## Duration (column I)
Always `N seconds` (e.g. `4 seconds`) so durations can be added up automatically.

## Audio (column H)
Prefix with the source: `VO:`, `<Character>:`, `SFX:`, `Music:`, `Ambience`, `Sync interview:`. Copy spoken lines word for word in the script's language. Shots with no speech still get an audio note (ambience, SFX, music cue, silence).
