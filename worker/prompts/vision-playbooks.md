# Vision playbooks

How each answer in the Vision Brief changes the breakdown. These are starting points; when the user's vision mixes them (for example a "funny true-crime doc"), blend them and say in the Brief which one leads.

## A. Format

| Format | Structure | Shot length | Coverage habits |
|---|---|---|---|
| **Narrated documentary / explainer** | Chapters; VO drives everything; recreations + archive + graphics + interviews | 3–8s | Pictures illustrate, they don't repeat the VO literally; recreations shot partly (backs, hands, silhouettes); one graphics system |
| **Interview-led doc** | Sync interview + B-roll | Interview 5–20s, B-roll 2–5s | 2 cameras (MCU + CU/profile); B-roll covers the edits; establish each interviewee in their space once |
| **Short film / drama** | Scenes with dialogue | Driven by performance | Master + singles + OTS + inserts per scene; motivated camera movement; hold on reactions |
| **Ad / commercial** | Hook (0–3s) → problem/desire → product → proof → CTA/end card | 1–3s, hero shot 3–5s | Product hero shots (INS, macro, slider), packshot end card with GFX, brand colour discipline, the logo or product legible on mobile |
| **Music video** | Driven by sections (verse/chorus/bridge) | Cut on the beat | Performance coverage (wide/mid/close of the artist) + narrative or concept B-roll; durations match the song's section lengths |
| **Reel / Short (9:16)** | Hook in the first 1–2s, payoff before 30–60s | 1–3s | Vertical framing: centred subjects, safe zones for captions top and bottom, punch-ins instead of wides |
| **Comedy sketch** | Setup → escalation → button | Hold for the joke | Wider frames and FS (the body and the timing are the joke), reaction cuts, a static camera that lets performers play; crash zooms only on the beat |
| **Corporate / brand film** | Story → values → people → future | 4–8s | Gimbal B-roll, polished interviews, clean graphics, optimistic light |

## B. Tone → craft choices
For lighting detail (vocabulary, how shot size changes the lighting, the arc of light) see `lighting-design.md`.


| Tone | Lens | Movement | Light / grade | Pace |
|---|---|---|---|---|
| Dark / crime / thriller | Long lenses to watch, wide for unease | Slow push-ins, nervous handheld, locked-off menace | Low key, hard shadows, cold or sodium palette, desaturated | Patient, with sudden cuts |
| Emotional / drama | 50–85, shallow depth | Slow, motivated | Soft, warm, natural | Let shots breathe |
| Happy / uplifting | 24–50 | Gimbal flow, crane up | High key, warm, saturated | Bright and rhythmic |
| Funny / goofy | Wide-ish (24–35), FS | Mostly static; snap zooms and whip pans as punchlines | Bright, flat, saturated | Timing beats; hold before the button |
| Epic / high-production | Very wide + long telephoto | Drone, crane, Steadicam | Contrast, sculpted | Build-ups and big releases |
| Energetic / hype | Mixed | Whips, speed ramps, rig mounts | Punchy | Fast, on the beat |
| Calm / meditative | 35–50 | Static, very slow slides | Natural, soft | Long holds |

## C. Production scale + method

- **High-budget live action:** anything goes: crane, drone, Steadicam, crowd extras, night exteriors. Note crew or gear needs ("Technocrane", "rain towers").
- **Run-and-gun / low budget:** handheld or gimbal, available light, real locations, small cast. Swap in cheaper versions of big shots (a phone timelapse instead of a drone hyperlapse) and say so in Notes.
- **AI-generated (Seedance, Veo, Kling, Wan, etc.):** clips are short, so **keep each shot ≤ 8–10s** and split longer beats. Write a Description that reads like a prompt: subject, action, setting, light, camera move, lens. Keep characters consistent by naming the same fixed costume and look each time. Avoid shots that need readable text, precise hands, or complicated multi-person interaction, or note them as `GFX overlay` or `practical insert`. Add `Ref: <character/location sheet>` to Notes.
- **3D / animation:** any camera move is possible; note the asset each shot needs. Physics or crowds cost time, so flag them.
- **Stock + motion graphics:** Descriptions should read like stock search terms. Lean on GFX; note `Stock search: ...`.

## D. Platform + aspect ratio + runtime

- **16:9 YouTube / TV:** standard compositions; lower-thirds in the bottom third.
- **9:16 Reels / Shorts / TikTok:** compose vertically; ELS and wide landscapes lose impact, so use punch-ins and tall subjects. Keep the top ~15% and the bottom ~25% clear of key action for UI and captions. Hook in the first 2s.
- **1:1 / 4:5 feeds:** centred, tight compositions.
- **2.39:1 cinema:** wide compositions, negative space, fewer cuts.
- **Runtime:** a target in the brief overrides the script's natural length. If the script cannot fit the target, say so in the Brief and propose what to cut or extend before building.
